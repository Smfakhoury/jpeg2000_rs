## Scope notes

- **F01:** Parser-produced tile extensions; descriptor selection, not a full pixel decode.
- **F02:** Direct marker-parser test; distinguishes PLM from PPM's different framing.
- **F03:** Small, parser-produced integer arrays; admission failure, not a complete transform-correctness claim.
- **F04:** Small tile-part fixtures; both descriptions are consistent.
- **F05:** Typed reconstruction stage with supplied decoded samples; not an entropy-decoder test.
- **F06:** Parsed geometry and validated selection; context coverage, not demonstrated rendered-color corruption.
- **F07:** Public decode_jph component output; does not require successful RGB conversion.
- **F08:** JP2 header parsing; later ignored boxes, not the separate first-box unknown-method question.
- **F09:** Metadata-parser record retention; not a complete color-rendering demonstration.
- **F10:** Public container parse; rejection prevents reaching later display behavior.
- **F11:** Fresh header-parser context; opaque/empty body, not decoded packet semantics.
- **F12:** Smallest witness is complete empty tile0; direct normalization, not a complete image decode.
- **F13:** Typed identity/cache lookup; preserving raw wire CSn is allowed. Existing metadata candidates are not promoted.
- **F14:** Small header-only mapping fixture13; local SOT-bearing reconstruction convention, not raw JPP tile-header wire format.
- **F15:** Fixture45 in the same replay as F14; separate geometry behavior, not a second independent test execution.
- **F16:** Four compact/extended header combinations; recursive metadata helper, not a complete JPX rendering.
- **F17:** No separately negotiated extension. Does not impose a universal reject-unknown rule on raw-header tools.
- **F18:** Complete small placeholder payload; even optional NCS=1 fails. No large stream enumeration.
- **F19:** Direct local SOT-bearing transition parser. Acceptance/sentinel confusion is established; the exact error category is inferred.
- **F20:** Ordinary Part 1, Rsiz=0; does not generalize to unresolved Part 2 directional cases.
- **F21:** Structural metadata-inspection contract; smallest input is an eight-byte empty box.
- **F22:** Parser-produced layers passed to the dedicated reference validator.
- **F23:** Smallest negative case is a 1037-byte box; this is a palette-validation gap.
- **F24:** Container-validation guarantee; not a claim that every permissive reader must reject every invalid file.
- **F25:** Two backing cases. File-structure/validation mismatch, not a universal reader-MUST-reject claim.
- **F26:** Project profile, not a claim that JPEG 2000 universally prohibits non-LRCP. No pixel corruption is established.
- **F27:** Public selected-decoder reproduction at discard=1. Originally inferred clause; the concrete coordinate/sample mismatch has separate source/fixture support.

## Editions and interpretation

The acquired editions are T.800 (2019-06), T.801 (2021-06), T.808 (2022-12), T.814 (2019-06), and T.803 (2024-02). The project selects newer T.800/T.801/T.808 editions; those differences remain unreconciled. T.803 was part of every original mapping batch but is not an independent authority for a row in this table.

F14 and F15 share one test and one diagnosed clause; F25 has two backing cases. Several rows share one build harness. Do not equate rows, tests, clauses, or diagnoses with a proven number of independent root causes.

Native/model agreement is not independent standards evidence. Recorded logs retain the original bounded output tails; `reproduce.py` saves complete output for new runs.
